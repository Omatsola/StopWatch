# StopWatch
A clean, responsive, and easy-to-use digital stopwatch built with HTML5, CSS3, and Vanilla JavaScript. It features start, stop, reset functionality, precise millisecond tracking, and a built-in Dark Mode toggle.

Demo Features

- Accurate Timing: Uses Date.now() timestamp offsets to prevent timer drift.
- Millisecond Precision: Displays MM:SS:MS in real time.
- Dark Mode Support: Seamless toggle between Light and Dark themes with saved user preference in localStorage.
- Responsive UI: Fully mobile-friendly and accessible design.

- Built With

- HTML5 - Semantic structure
- CSS3 - Custom properties (variables), Flexbox, transitions
- JavaScript (ES6+) - Intervals, DOM manipulation, local storage

Project Structure

Text
- index.html:    Page structure & content
- style.css:   Styling & CSS variables for themes
- script.js:    Stopwatch logic & theme switcher
